# Dashboard

Dashboard personnel affichant la météo, les transports en commun et un globe 3D interactif.

## Fonctionnalités

- **Météo** : Conditions actuelles et prévisions via Open-Meteo API
- **Transports** : Prochains départs depuis les arrêts proches (Swiss Transport API)
- **Globe 3D** : Visualisation interactive avec cycle jour/nuit en temps réel

## Utilisation

Ouvrir `index.html` dans un navigateur ou visiter : https://flo5k5.github.io/dashboard/

## Contrôles du globe

- Glisser pour faire tourner
- Molette pour zoomer
- Double-clic pour recentrer sur votre position
